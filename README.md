# 일기장 · 기기 연동

[다이어리 열기](https://bokbok7717-eng.github.io/diary-main/)

## 처음 연결하기

1. 기존 일기가 있는 기기에서 백업을 내려받습니다.
2. 상단 ☁️ 버튼 → 이메일·새 비밀번호 입력 → **처음 이용해요**를 누릅니다.
3. 가입 확인 메일을 누르고 다이어리로 돌아와 로그인합니다. Supabase 관리용 계정과 다이어리 계정은 별개입니다.
4. **이 기기 내용으로 연결**을 눌러 클라우드 저장을 시작합니다.
5. 다른 기기에서 같은 주소·같은 이메일로 로그인하고 **저장된 내용 불러오기**를 누릅니다.

저장한 일기는 약 1초 뒤 전송합니다. 설정 등의 변경은 화면이 열려 있는 동안 최대 20초 간격으로 확인합니다. 화면을 닫기 전 ☁️에서 저장 완료를 확인하세요. 다른 기기의 변경은 자동으로 편집 화면을 교체하지 않으며, 알림을 확인하고 불러옵니다.

## Supabase 설정

- SQL Editor에서 `supabase/setup.sql` 실행. 이미 같은 테이블과 정책이 있으면 건너뜁니다.
- Authentication → URL Configuration의 Site URL: `https://bokbok7717-eng.github.io/diary-main/`
- 같은 주소를 Redirect URLs에도 등록합니다.
- 이메일 로그인과 이메일 확인을 켜둡니다.
- `cloud-sync.js`에는 프로젝트 URL과 **publishable key**만 넣습니다. Secret/service_role 키는 넣지 않습니다.
- 로컬 테스트: `python3 -m http.server 8765`로 실행. `file://`로 직접 열지 않습니다.

## 저장과 충돌 처리

개인 일기·커플 기록·참조된 사진·꾸미기 설정을 기존 `diary_sync`의 사용자별 JSON 스냅샷으로 저장합니다. 초안, 앱 잠금 PIN, 로그인 토큰은 동기화 대상에서 제외합니다. 사진을 포함한 전체 전송 자료는 15MiB까지 지원합니다. 큰 사진 라이브러리는 별도 Storage 설계로 확장해야 합니다.

업데이트는 마지막으로 읽은 `version`과 일치하는 행에만 적용합니다. 다른 기기에서 먼저 저장했다면 덮어쓰지 않습니다. 양쪽에서 수정했다면 먼저 이 기기 백업을 받고, 클라우드를 불러온 뒤 필요한 내용을 옮겨주세요. 백업을 전체 복원하면 기존 앱의 동작대로 현재 자료를 대체하므로 개별 병합 용도로 사용하지 않습니다.

클라우드 내용을 불러올 때 현재 자료의 백업 파일을 내려받고, 사진 저장 완료 후 로컬 자료를 교체합니다. 로그아웃해도 이 기기의 기록은 남습니다. 공동 기기에서는 이 점을 고려하세요. 커플 모드는 같은 계정의 데이터에 포함되며, 별도 계정 간 공유 기능은 아닙니다.
