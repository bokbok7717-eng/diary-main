# Hachiware theme artwork

Character: Hachiware (Chiikawa), by Nagano. Rights belong to their respective owners.
The five source PNG files were supplied by the user on 2026-10-21 and preserved without raster edits.

- profile.png: onigiri character, default portrait in both modes.
- heart.png: couple sidebar decoration only.
- shark.png: diary sidebar decoration.
- festival.png, snail.png: faint grayscale repeat pattern, arranged in pattern.svg.

face-lock.png: face-only derivative created with the built-in image generation tool from profile.png. Prompt: preserve Hachiware face, blue ears, original colors and expression; remove body and rice ball; complete rounded chin; transparent background.
