# Mood chart animations

Six original animated GIF files provided by the user on 2026-10-21. Binary files are copied unchanged, retaining every frame and original timing.
Characters: Chiikawa, Hachiware, Usagi (Chiikawa), by Nagano; rights belong to their respective owners.

Each character has a diary and couple variant. CSS sets upper-body framing; the Chart.js arc geometry positions and clips the image inside the doughnut hole.
